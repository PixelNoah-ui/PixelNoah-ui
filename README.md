## Introduction

I design and build full-stack products end to end — from data modeling and API architecture through to the interface people actually touch. My focus is the intersection of **solid engineering** and **thoughtful UI**: systems that scale cleanly, and screens that feel considered.

I care most about three things — **performance**, **maintainability**, and **craft**. Code that's fast to run, easy to change six months from now, and pleasant to use today.

## Architecture Philosophy

<table>
<tr>
<td width="25%" valign="top">

**Simple by default**
<br>
<sub>The straightforward solution ships first. Complexity is earned, not assumed.</sub>

</td>
<td width="25%" valign="top">

**Typed end to end**
<br>
<sub>Types at the boundary — API, database, UI — catch mistakes before runtime.</sub>

</td>
<td width="25%" valign="top">

**Boring where it counts**
<br>
<sub>Proven tools for the core. Novelty is reserved for where it actually adds value.</sub>

</td>
<td width="25%" valign="top">

**Designed, not decorated**
<br>
<sub>UI decisions come from the user flow first, styling second.</sub>

</td>
</tr>
</table>
